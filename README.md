# Rust 语言程序设计 课程简介

本课程面向对计算机编程感兴趣、希望深耕底层技术的学生，系统讲解 Rust 编程语言的核心知识与编程实践。课程整体学习难度与 C++ 相近，入门门槛不高，但想要熟练掌握需要深刻理解语言内在的内存安全逻辑。

## 课程考核

- 实验占比：**30‑40%**
- 闭卷考试占比：**60‑70%**

> 
> 实验要求：报名秋冬季开源操作系统训练营，完成约 110 道 Rust 线上自动评测习题，在第 15 周前将完成情况截图上传至 BB 平台。

## 学习资源

配套线上教材：[Rust 语言圣经](https://course.rs/about-book.html)，每个小节后附带在线练习题，便于课下自学巩固。

## 课程定位与价值

Rust 是一门兼顾高性能与内存安全的系统编程语言，同时具备 C 语言的运行效率与 Java 的表达能力。
C/C++ 灵活高效，但指针、手动内存管理容易出现悬空指针、二次释放、内存泄漏等问题。Rust 在编译阶段完成内存安全校验，广泛应用于底层系统开发，也逐步向应用开发领域拓展，华为、蚂蚁等大厂均有相关技术岗位需求。

修读本课程可以参加**教育部白名单 A 类赛事：全国大学生计算机系统能力大赛**，往届课程学员多次获得国家级竞赛奖项。

## 课程主要内容

1. **开发环境入门**
   - Rust 环境安装，`rustup`工具链
   - Cargo 包管理器基础，项目创建与构建运行
   - VSCode + `rust‑analyzer`开发调试环境
2. **变量、所有权和借用**
   - 变量绑定、可变性、变量遮蔽
   - 基础数据类型：数值、字符、布尔、单元类型
   - 语句与表达式区别，函数定义、参数、返回值规则
   - 栈与堆内存模型，所有权规则、move 移动、`Copy`/`Clone`
   - 引用与借用：不可变引用、可变引用、悬垂引用编译检查
3. **复合数据类型**
   - `String`可变字符串与`&str`字符串切片，UTF‑8 切片索引
   - 元组、结构体、枚举（携带关联数据的高级枚举）
   - `Option<T>`枚举：消除传统空指针问题
   - 定长数组 array，Rust 数组越界检查与 C 语言行为对比
4. **流程控制与模式匹配**
   - `if‑else`表达式；`for`/`while`/`loop`循环
   - `match`模式匹配、模式守卫、嵌套解构
   - `if‑let` / `while‑let`语法，处理`Option<T>`
   - 和 C 语言`switch‑case`对比，理解模式匹配的安全与表达优势
5. **方法、泛型与特征 (trait)**
   - `impl`实现块；`&self` / `&mut self` / `self`接收者；关联函数
   - 泛型：函数、结构体、方法中的泛型参数
   - Trait 特征："can‑do" 能力模型，与 C++ 虚函数继承`is‑a`的区别
   - 特征实现、默认实现、特征约束、`impl Trait`、孤儿规则
6. **集合类型**
   - 动态数组`Vec<T>`：创建、push 追加、下标访问 / `get()`安全读取
   - `HashMap`哈希映射：插入、查询、更新、`entry‑or_insert`用法
   - 集合场景下所有权与借用注意事项
7. **生命周期**
   - 借用检查器原理，悬垂引用产生原因
   - 生命周期标注语法，函数引用参数 / 返回值生命周期约束
   - 生命周期作为编译契约，在编译期杜绝悬垂引用

## 课程学习目标

通过课程学习，不仅能够独立编写 Rust 应用程序，同时建立严谨的内存安全编程思维，理解现代系统编程语言的设计哲学，为后续操作系统、嵌入式开发、高性能服务端开发方向打下扎实基础。
